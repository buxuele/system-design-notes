# 第9章：设计网络爬虫

## 引言
**网络爬虫**（也称为蜘蛛或机器人）用于发现和收集网页内容，例如网页、图片和视频。本章重点在于设计一个可扩展的网络爬虫，用于**搜索引擎索引**。

### 网络爬虫的应用
1. **搜索引擎索引：** 收集网页以创建可搜索的索引（例如 Googlebot）。
2. **网络归档：** 保留网页数据以供未来使用（例如美国国会图书馆）。
3. **网络挖掘：** 从网页数据中提取知识（例如股东报告的财务分析）。
4. **网络监控：** 检测版权或商标侵权行为。

### 设计挑战
一个优秀的网络爬虫必须解决以下问题：
- **可扩展性：** 通过并行化处理数十亿个网页。
- **鲁棒性：** 处理格式错误的 HTML、系统崩溃和恶意链接。
- **礼貌性：** 避免向服务器发送过多请求。
- **可扩展性：** 以最小改动支持新的内容类型。

---

## 第1步：理解问题

### 需求
1. 每月爬取**10亿个网页**（400页/秒，峰值800 QPS）。
2. 仅收集**HTML内容**。
3. 追踪新增和更新的页面。
4. 忽略重复内容。
5. 存储爬取数据**5年**，大约需要30 PB的存储空间。

## 第2步：高层设计

### 组件

1. **种子URL：** 爬虫的起始点。
    - 需要精心选择，以便爬虫能够利用它遍历尽可能多的链接。
    - 可以基于不同热门网站的区域或主题进行划分。
    - 策略：按区域或主题分类（例如体育、医疗）。

2. **URL前沿：** 存储待下载的URL。
   - 以**FIFO队列**的形式实现。

3. **HTML下载器：** 从URL前沿提供的URL下载网页。

4. **DNS解析器：** 将URL转换为IP地址。

5. **内容解析器：** 验证并解析网页。
   - 丢弃格式错误的页面。

6. **内容已见？：** 通过哈希比较检查重复内容（比较两个网页的哈希值）。

7. **内容存储：** 将HTML页面存储在磁盘上（热门内容存储在内存中以降低延迟）。

8. **URL提取器：** 从解析后的页面中提取新链接。

9. **URL过滤器：** 排除黑名单或错误的URL。

10. **URL已见？：** 追踪已访问的URL以避免重复。

11. **URL存储：** 存储已访问的URL。

---

### 工作流程
1. 将**种子URL**添加到URL前沿。
2. **HTML下载器**获取URL并通过DNS解析器解析其IP地址。
3. **内容解析器**验证内容并传递给"内容已见？"组件。
4. 如果内容是新提取的，则通过**URL提取器**提取链接。
5. 过滤并将唯一链接添加到URL前沿。

## 第3步：深入关键组件
### DFS/BFS
-  网络可以被看作一个有向图，其中网页是节点，超链接（URL）是边。
-  通常使用BFS进行图遍历，因为深度可能非常深，因此DFS不是理想选择。
-  标准BFS不考虑URL的优先级，并非每个页面都具有相同的重要性和优先级。

### URL前沿
- **礼貌性：**
    - 确保同一时刻每个主机只发送一个请求。在两个下载任务之间添加延迟。
    - 使用从主机名到队列和工作（下载）线程的映射。
    - 每个下载线程拥有独立的FIFO队列，并且只从该队列下载URL。

        <img src="./images/politeness.png" alt="Politeness" width="500">

    - **队列路由器：** 确保每个队列（b1, b2, … bn）只包含来自同一主机的URL。
    - **映射表：** 将每个主机映射到一个队列。
    - **队列选择器：** 每个工作线程映射到一个FIFO队列，并且只从该队列下载URL。队列选择逻辑由队列选择器完成。
    - **工作线程1到N。** 工作线程按顺序从同一主机下载网页。可以在两个下载任务之间添加延迟。

- **优先级：**
    - 为重要页面分配更高的优先级（例如按PageRank或更新频率）。

        <img src="./images/prioritizer.png" alt="Politeness" width="500">
    
    - **优先级排序器：** 接收URL作为输入并计算优先级。
    - **队列f1到fn：** 每个队列被分配一个优先级。优先级高的队列被选中的概率更高。
    - **队列选择器：** 随机选择一个队列，但偏向优先级更高的队列。
    - **前队列：** 管理优先级。
    - **后队列：** 管理礼貌性。

- **新鲜度：** 根据更新历史或重要性重新爬取。

### HTML下载器
- **Robots.txt合规性：** 遵守robots.txt文件中的规则。
- **性能优化：**
  1. 使用多台服务器进行分布式爬取。
  2. 使用**DNS缓存**避免重复查询。
  3. 地理分布爬取服务器以加快下载速度。
  4. 使用较短的超时时间以避免响应缓慢或无响应的服务器。

### 鲁棒性
1. **一致性哈希：** 有效分配服务器间的负载。
2. **错误处理：** 防止异常导致系统崩溃。
3. **数据验证：** 确保内容完整性。

### 可扩展性
- 为新的内容类型添加模块（例如，PNG 下载器、网页监控器）。
- 示例：插入一个模块来监控网页内容中的版权违规行为。

    <img src="./images/extensibility.png" alt="Politeness" width="600">
---

### 避免问题内容
1. **重复内容：** 使用哈希比较进行检测。
2. **蜘蛛陷阱：** 通过 URL 长度限制等技术避免无限循环。
3. **数据噪声：** 过滤无关内容，如广告或垃圾信息。

---

## 第4步：总结
### 核心要点
1. 网络爬虫必须在可扩展性、鲁棒性、礼貌性和可扩展性之间取得平衡。
2. **礼貌性** 防止服务器过载，而 **优先级** 确保重要页面优先被爬取。
3. 高效的存储和错误处理对于应对大规模爬取至关重要。

### 其他考虑事项
- **服务端渲染：** 处理由 JavaScript 或 AJAX 生成的动态内容。
- **反垃圾措施：** 排除低质量或无关的页面。
- **数据库分片：** 通过复制和分片扩展数据层。
- **水平扩展：** 使用无状态服务器高效扩展爬取任务。
- **分析：** 收集并分析数据以获取洞察。
